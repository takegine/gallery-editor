# 游廊编辑器 (Gallery Editor)

## 由来
这是一个融合了
 - zombiej的kveditor
 - zombiej的matrix-editor
 - darkload的aghnims_editor

并加入了一点自己的想法制作的gallery-editor

## 预期
1. 相较于原版的编辑器，大大提高vdf文件的读写速度
2. 做一个大家喜欢用的辅助工具
3. 做一点轻度商业化的想法

## 功能大纲
#### 基础功能
1. 修改出场可选的原生英雄
2. 配置自定义物编，包括英雄，单位，技能和物品
3. 配置方言

#### 进阶功能【待开发】
4. 配置商店的货架
5. 表格化物编的配置
6. 自动翻译
7. 输出json

## 项目支持
